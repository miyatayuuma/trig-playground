# First live labyrinth transition

The first semantic transition is intentionally narrow:

1. Focus the unit-circle face from the existing 3D trig box.
2. Start a swipe at the unit-circle origin and move outward.
3. The existing radius is preserved and gains an arrowhead.
4. The circle and theta trail fade while an XY grid and vector components emerge.
5. The rotating point remains the same shared `(cos θ, sin θ)` state.
6. Tap or swipe in the vector room to reverse the morph back to the unit circle.

This establishes the interaction contract for future gateways without introducing a topic menu or a hard page transition.
